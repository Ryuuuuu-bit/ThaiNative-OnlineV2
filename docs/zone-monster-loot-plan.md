# แผนโซน มอนสเตอร์ และของล่า Lv.1–40

วันที่: 22 ตุลาคม 2026 · สถานะ: ชุดมอนสเตอร์และไอเทม Lv.1–10 พร้อมทดลองในเครื่อง; Lv.11–40 ยังเป็นแผน

## ชุดทดลองที่ลงระบบแล้ว

เปิดได้ที่ http://localhost:5185/loot-preview ขณะรัน `.codex-run/starter-loot-preview.mjs` มีตัวละคร Lv.5 และ Lv.10 พร้อมอุปกรณ์ให้เทียบในกระเป๋า ใช้ MemoryStore แยกจากข้อมูลจริง; รีโหลด/กลับเข้าเกมเก็บค่าเดิมได้ แต่ปิดเซิร์ฟเวอร์ทดลองแล้วข้อมูลชุดนี้จะหาย

- อุปกรณ์ฐานนักสำรวจ 8 ชนิด สุ่ม Magic/Rare รายชิ้น เก็บค่าตั้งแต่ดรอป มี Prefix/Suffix และแสดงช่วงตัวเลข ไม่สุ่มซ้ำตอนเก็บ ฝาก ถอน หรือแลกของ
- การ์ดเฉพาะตัวครบ 18 ใบ พร้อมเอฟเฟกต์ใน combat และมอนสเตอร์ Lv.1–10 ทั้ง 18 ชนิด ดูรายการที่ลงจริงใน [starter-monsters-lv1-10.md](starter-monsters-lv1-10.md) การ์ดเดิมรักษาช่องสวมและโบนัสเพื่อรองรับของที่ผู้เล่นมีอยู่
- Unique มงกุฎแอ่งน้ำ Lv.5 และถุงมือทอหมอก Lv.10 มีค่าสุ่มประจำชิ้นและเอฟเฟกต์ทำงานจริง Unique ชุดนี้เจาะ/ใส่การ์ดไม่ได้
- ชุดแรกปรับบางเอฟเฟกต์ให้ทดสอบได้กับระบบปัจจุบัน: การ์ดหมาป่าฟื้น 3 SP เมื่อโจมตีปกติคริติคอล (CD 6 วินาที); ถุงมือสร้างพิษแบบรีเฟรช 4 วินาที ไม่ซ้อนหลายชั้น; มงกุฎรักษาเฉพาะผู้สวมในแอ่งและเพิ่มคูลดาวน์ยาร่วม HP/SP
- แหล่ง Unique: ราชาวุ้น → มงกุฎแอ่งน้ำ 8%; แม่รังหนาม Lv.10 → ถุงมือทอหมอก 8% ยกเลิกแหล่งชั่วคราวจากหมาป่าเงาแล้ว การ์ดปกติ 0.1%, Elite 0.2%, บอส 0.5% ก่อนตัวคูณดรอป; ยังต้องปรับสมดุลจากเวลาเล่นจริง
- ไอคอนอุปกรณ์/การ์ดใหม่และการ์ดวุ้นสองใบใช้ SVG ที่วาดขึ้นเอง มีหลักฐานที่ `meadow-3d/public/assets/starter-loot/provenance.json`
- เพิ่ม migration `server/sql/020_item_rolls.sql` แบบเพิ่มคอลัมน์ โดยของเดิมไม่มี roll และคงค่าสถานะเดิม การถอดการ์ดที่ NPC และระบบคราฟต์ออฟยังอยู่ในแผนขั้นถัดไป

ตาราง 48 มอน/48 การ์ด/8 Unique ด้านล่างเป็นเป้าหมายครบชุด ไม่ใช่จำนวนที่พร้อมเล่นแล้ว ยังไม่ deploy

## โซนกรีกเพิ่มเติม

เพิ่มโซนวิหารกรีก Lv.40–49 ตามคำขอใหม่: ซาเทอร์ 40, ฮาร์ปี 43, กอร์กอน 46, มิโนทอร์บอส 49 พร้อมการ์ด/วัตถุดิบเฉพาะ 4 ชุด ดู [รายละเอียดที่ลงระบบ](greek-temple-lv40-49.md) ยังไม่ deploy และไม่รวมอยู่ในเป้าหมาย 48 ชนิดเดิมด้านล่าง

## เป้าหมายและขอบเขต

ให้ผู้เล่นเลือกพื้นที่จาก EXP วัตถุดิบ อุปกรณ์ การ์ด และความท้าทาย แต่ละโซนมีรูปร่างมอน พฤติกรรม และของเฉพาะที่จำได้ ไม่เพิ่มความหลากหลายด้วยการเปลี่ยนสีหรือขนาดอย่างเดียว

เป้าหมายชุดนี้: **48 ชนิด — ปกติ 29, Elite 11, Boss 8** พร้อมการ์ดเฉพาะชนิด 48 ใบ และ Unique ประจำบอส 8 ชิ้น ตัวเลขเอฟเฟกต์ทั้งหมดเป็นค่าตั้งต้นสำหรับทดสอบ ไม่ใช่ค่าที่สมดุลแล้ว

ของล่าแบ่งเป็น 3 ระบบที่มีหน้าที่ต่างกัน:

1. **Rare สุ่มออฟ**: ปรับค่าสถานะและปิดจุดอ่อนของบิลด์ อุปกรณ์ฐานเดียวกันต่างกันได้เป็นรายชิ้น
2. **Unique**: มีรายการความสามารถประจำรุ่น บางบรรทัดสุ่มเฉพาะตัวเลข มีจุดเด่นหรือข้อแลกเปลี่ยนที่เปลี่ยนวิธีเล่น
3. **Card**: เอฟเฟกต์คงที่ตามชนิดการ์ด ใส่ในช่องอุปกรณ์ที่กำหนด ให้เหตุผลกลับไปล่ามอนทุกช่วงเลเวล

## ผังโซนและการเดินทาง

ยังใช้ 7 แมปปัจจุบัน: city_plaza, meadow, forest, ruins, canyon, grove, summit โดยแบ่งพื้นที่ย่อย ไม่ถือว่าโซนใหม่ในเอกสารนี้มี geometry หรือประตูพร้อมแล้ว

| Lv. แนะนำ | พื้นที่ย่อย | เป้าหมายการล่า | จำนวน ปกติ / Elite / Boss |
|---|---|---|---|
| 1–5 | สวนใบบัว ใต้เมือง / meadow | ยา ฟื้นฟู อุปกรณ์เริ่มต้น | 2 / 1 / 1 |
| 1–5 | ชายป่าใบชา ตะวันออก / forest | SP หลบหลีก วัตถุดิบสายเวท | 2 / 1 / 0 |
| 1–5 | ลานดินเผา เหนือเมือง / ruins | เกราะ โล่ วัตถุดิบสายป้องกัน | 2 / 1 / 0 |
| 1–5 | ลำธารกรวด ตะวันตก / canyon | ความแม่นยำ ความเร็ว วัตถุดิบอาวุธ | 2 / 1 / 0 |
| 6–10 | สวนเห็ดและพงหนาม / forest | พิษ เลือดไหล การเคลื่อนที่ | 3 / 1 / 1 |
| 11–15 | บึงโคมและป่าราก / forest | เวท SP รักษา และป้องกัน | 3 / 1 / 1 |
| 16–20 | จัตุรัสอักขระ / ruins | ตัดจังหวะ เวทต่อเนื่อง และคริติคอล | 3 / 1 / 1 |
| 21–25 | วิหารปลายผาและเหมืองชั้นนอก / canyon | ทำลายเกราะ บล็อก และสวนกลับ | 3 / 1 / 1 |
| 26–30 | แอ่งอำพันและสันเขา / canyon | ฝุ่น ลม การโจมตีพื้นที่ | 3 / 1 / 1 |
| 31–35 | ป่าอำพัน / grove | คอมโบ เรซิน บัฟกลุ่ม | 3 / 1 / 1 |
| 36–40 | ยอดเขาจันทรา / summit | น้ำแข็ง เกราะผลึก และกลไกบอส | 3 / 1 / 1 |

ทั้ง 4 ประตูมีทางเริ่ม Lv.1–5 ที่ปลอดภัยพอ ๆ กัน และให้ของคนละแนว ต้องมีทางเดินเชื่อมเขตเริ่มต้นไปพื้นที่ Lv.6–10 โดยไม่บังคับผ่านมอน Lv.20+ เช่น ถนนคาราวาน canyon → forest และทางสวนเก่า ruins → forest เส้นทางเหล่านี้เป็นงานแมปที่ต้องทำเพิ่ม

พื้นที่ชั้นสูงใช้ทางเข้าเชื่อมตามลำดับ forest → ruins → canyon → grove → summit พร้อมป้าย Lv. ที่ทางแยก พื้นที่ boss เป็นทางอ้อมไม่บังคับขวางถนนหลัก บอสไม่ใช่เงื่อนไขปลดล็อกการเก็บเลเวลถัดไป

ระดับความยากเพิ่มด้วยความซับซ้อนของท่าและการวางตำแหน่ง คงกลุ่มมอนกระจายตัวและทางหนีให้ผู้เล่นเดี่ยว Elite มีสัญญาณเตือนเฉพาะและ Boss มีลานแยก

## อุปกรณ์สุ่มออฟ

ค่าฐานของชนิดอุปกรณ์แยกจากออฟสุ่มและการตีบวก ระบุ level สองค่า: **itemLevel** จากแหล่งดรอปใช้เปิดช่วงออฟ และ **requiredLevel** ใช้ตรวจสิทธิ์สวมใส่

| ระดับของ | รายการสุ่มออฟ | บทบาท |
|---|---|---|
| Common | 0 | ใช้งานเริ่มต้นและเป็นฐานสำหรับคราฟต์ |
| Magic | 1–2 สูงสุด Prefix 1 + Suffix 1 | อ่านง่าย มีออฟเด่นหนึ่งด้าน |
| Rare | 3–6 สูงสุด Prefix 3 + Suffix 3 | เป้าหมายล่าอุปกรณ์รายชิ้นและปรับบิลด์ |
| Unique | รายการประจำรุ่น ไม่สุ่มหยิบจาก pool ทั่วไป | ให้ความสามารถเฉพาะชิ้นและข้อแลกเปลี่ยน |

Rare Lv.ต่ำไม่ควรได้หกออฟแรงพร้อมกันง่าย ๆ น้ำหนักจำนวนออฟและช่วงตัวเลขเพิ่มตาม itemLevel ใช้ 4 ช่วงเปิด tier สำหรับเริ่ม: 1–10, 11–20, 21–30, 31–40 แต่ค่าภายในยังไล่ตามเลเวล ไม่กระโดดพลังทุกสิบเลเวล

- Prefix: พลังโจมตี HP SP เกราะ พลังเวท ตามชนิดอุปกรณ์
- Suffix: ความเร็วโจมตี ความแม่นยำ คริติคอล ต้านธาตุ และลดเวลาสถานะ ตามชนิดอุปกรณ์
- ทุกออฟมี family; ห้ามสุ่ม family เดียวกันซ้ำในชิ้นเดียว ห้าม affix ที่ใช้ไม่ได้กับอุปกรณ์นั้น
- ไม่บังคับให้ความสามารถพิเศษมีเฉพาะคริติคอล/ดาเมจ เพื่อให้สายรักษา แทงก์ และเก็บวัตถุดิบมีของที่อยากได้
- Tooltip แสดงออฟแยกบรรทัด ช่วงที่สุ่มได้ tier แหล่งกำเนิด และช่องการ์ด ผู้เล่นควรประเมินของได้ในเกม
- ออฟสุ่มต่อชิ้นต้องถูกสร้างและบันทึกโดย server ตั้งแต่ดรอป ครั้งต่อไปที่ login/trade/store จะต้องเป็นค่าเดิม

คราฟต์เริ่มจากวัสดุเปลี่ยนค่าตัวเลขในบรรทัดเดิม และวัสดุสุ่มเปลี่ยนหนึ่งบรรทัด แยกกัน หินยึดออฟเป็นขั้นถัดไปหลังเศรษฐกิจผ่านการทดสอบ ไม่จำเป็นต้องเปิดพร้อมระบบแรก

รายการบรรทัดและเอฟเฟกต์ประจำรุ่นเหมือนกันทุกชิ้น ตัวเลขที่อยู่ในช่วงสุ่มครั้งเดียวเมื่อเกิดไอเทม การตีบวกไม่เพิ่มความแรงของเอฟเฟกต์พิเศษโดยอัตโนมัติ

| Lv. / แหล่ง | Unique / ช่องอุปกรณ์จริง | บรรทัดประจำรุ่นตัวอย่าง | ความสามารถเฉพาะและข้อแลกเปลี่ยน |

คำว่าโจมตีหนัก เวทต่างชนิด และเกราะชั่วคราวต้องระบุ skill tags และกติกาให้ชัดก่อนลงระบบจริง เกมยังไม่จำเป็นต้องมีระบบหลบแบบกดปุ่มเพื่อใช้ Unique เหล่านี้

Unique ไม่ใช่ Rare ที่เก่งกว่าทุกด้าน Rare ออฟดีควรชนะด้านค่าสถานะรวมได้ ส่วน Unique ชนะในบิลด์ที่ใช้ความสามารถประจำชิ้นได้คุ้ม แผนเริ่มให้ Unique ไม่มีช่องการ์ด เพื่อรักษาตัวเลือก Rare + Card; ชิ้นใดจะมีช่องต้องออกแบบและทดสอบเป็นข้อยกเว้นรายชิ้น

## กติกาการ์ดและป้องกันคอมโบไร้ขอบเขต

- ทุกมอนในตารางมีการ์ดเอฟเฟกต์เฉพาะ ไม่สุ่มเอฟเฟกต์หรือค่าตัวเลขเมื่อดรอป การ์ดไม่ใช่ affix อีกชุด
- เริ่มสูงสุด 1 ช่องต่ออุปกรณ์ Rare และกำหนดตำแหน่งตามตาราง ต้องตรวจข้อมูลผู้เล่นเดิมก่อนเปลี่ยนเพดานรูหรือกติกาการเจาะช่อง ไม่ลบรู/การ์ดที่มีอยู่โดยไม่วางแผนย้าย
- การ์ดชนิดเดียวกันไม่ทำงานซ้ำหลายชิ้น แม้ใส่ได้มากกว่าหนึ่งช่องประดับ UI ต้องอธิบายกติกานี้
- เอฟเฟกต์ที่เกิดจาก proc ไม่ทริกเกอร์ proc อื่น เว้นแต่ระบุเป็นกรณีพิเศษ; summon และดาเมจต่อเนื่องไม่ถือเป็นผู้เล่นโจมตีปกติโดยอัตโนมัติ
- การรักษาตัวเอง การรักษาเพื่อน overheal และโล่ชั่วคราวต้องนิยามแยกกัน ไม่ให้สร้างวงจรเกราะ/รักษาอนันต์
- เอฟเฟกต์หมู่มีเพดานจำนวนเป้าหมาย ระยะ คูลดาวน์ และเจ้าของดาเมจชัดเจน
- บอสมีการลดผลของ slow/interrupt ตามชนิด ไม่ให้การ์ดตรึงบอสถาวร
- กฎคูลดาวน์ควรใช้ร่วมกันใน effect family ที่ทับกัน เพื่อปิดช่องสลับอุปกรณ์หลบคูลดาวน์
- การ์ดบอสเป็นตัวเลือกเฉพาะทาง ไม่ใช่แรงกว่าการ์ดปกติทุกสถานการณ์ การ์ดเลเวลต่ำยังใช้ถึง Lv.40 ได้โดยมีเพดานค่าฟื้น/เกราะตามเลเวลตัวละครที่สมดุลแล้ว
- ถอดการ์ดที่ NPC โดยมีค่าใช้จ่ายและยืนยันก่อนทำ ไม่ทำลายการ์ดเป็นค่าเริ่มต้น ตัวเลขค่าถอดต้องอิงรายได้จริงจากการเล่น

## การดรอปและเหตุผลให้กลับมาล่า

| สิ่งที่ล่า | แนวทางแหล่งดรอป |
|---|---|
| วัตถุดิบเฉพาะ | จากชนิดมอนในตาราง มีโอกาสได้บ่อยพอให้หนึ่งรอบฟาร์มมีความคืบหน้า |
| อุปกรณ์ Rare | ทุกโซนมีอุปกรณ์หลายฐาน; บางตระกูลมอนมีน้ำหนักอาวุธ/เกราะบางชนิดมากกว่า แต่ไม่ผูกทุกบิลด์กับแมปเดียว |
| Card | เฉพาะมอนเจ้าของใบ มีเอฟเฟกต์คงที่ และมีช่องทางแลกเปลี่ยนกับผู้เล่น |
| Unique | ประจำบอสตามตาราง มีโอกาสดรอปตรง และวัตถุดิบเฉพาะบอสใช้เป็นเส้นทางสะสมสร้างรุ่นเดียวกันได้ |

ยังไม่ล็อกเปอร์เซ็นต์ Card/Unique จนมีค่าจำนวน kill ต่อชั่วโมง เวลาเกิดบอส และจำนวนผู้มีสิทธิ์รับของจริง ต้องออกแบบจากเวลาได้ของที่คาดหวัง ไม่ยืมอัตรา 0.01% ของเกมอ้างอิงมาใช้ตรง ๆ การแบ่งรางวัลบอสต้องกำหนดสิทธิ์จากการมีส่วนร่วมเพื่อไม่ให้ last hit อย่างเดียวครอบครองของ

เลเวลมอนกับผู้เล่นใช้ปรับ EXP แยกจากของดรอป เพื่อให้กลับมาหาการ์ด/วัสดุเก่าได้ สูตรเริ่มทดสอบ: มอนต่ำกว่า 0–3 ระดับ EXP 100%, ต่ำกว่า 4–5 ได้ 70%, ต่ำกว่า 6–8 ได้ 30%, ต่ำกว่า 9+ ได้ 10%; สูงกว่า 1/2/3+ ได้ 110/115/120% สูงสุด ต้องป้องกันลากเลเวลด้วยกติกาแบ่ง EXP ตามการมีส่วนร่วมและระดับสมาชิกปาร์ตี้ก่อนเปิดจริง กติกาบอส/ลูกสมุนแยกจากมอนปกติ

## ฐานโค้ดก่อนทำชุดทดลอง และลำดับงานที่วางไว้

บันทึกฐานเดิมก่อนลงระบบทดลองจาก shared/data/monsters.json, shared/data/items.json และ shared/src/inventory.ts; สถานะที่ทำแล้วอ่านจากส่วนชุดทดลองด้านบน:

- มี monster records 38 รายการ รวมลูกสมุนและตัวรุ่นย่อย ใช้หลาย sprite source ร่วมกัน
- มี OwnedItem.id, template, refine, cards และ sockets ใช้เป็นฐานการ์ดและข้อมูลรายชิ้นได้
- มีรายการการ์ดวุ้นและบอสอยู่แล้ว: modifiers ใน item template ว่าง แต่โบนัสจริงมาจาก shared/data/cards.json (วุ้นเพิ่ม VIT/HP และราชาวุ้นเพิ่มดาเมจต่อ formless) ชุดทดลองเพิ่มเอฟเฟกต์เฉพาะตัวโดยเก็บโบนัสเดิม
- OwnedItem ยังไม่มี affix rolls, itemLevel หรือรายการค่าพิเศษ Unique ที่สุ่มต่อชิ้นใน interface นี้ ต้องต่อข้อมูลผ่าน persistence, drops, inventory, storage, trading, derived stats, combat และ tooltip อย่างครบถ้วน
- ค่าความสามารถ Card และ Unique ในเอกสารนี้ยังไม่ถูกใส่ลง runtime

ลำดับลงมือ:

1. ทำระบบข้อมูลอุปกรณ์รายชิ้นและการย้ายข้อมูลเดิมก่อน เพิ่มสุ่มออฟ + ค่าสุ่ม Unique + ช่องการ์ด โดย server เป็นผู้ตัดสินและบันทึก
2. เปิดชุดแนวตั้ง Lv.1–10: มอนที่หน้าตาต่างกันจริง, Rare สุ่มออฟ, การ์ดทดสอบต่างบทบาท, Unique สองบอส ทดสอบดรอป→เก็บ→สวม→ถอด→ฝาก→แลก→กลับเข้าเกม
3. ปรับแมป/ถนนและทยอยเปลี่ยนรายชื่อครบ Lv.40 พร้อมภาพต้นฉบับและพฤติกรรมจริง ห้ามให้ tooltip อ้างเอฟเฟกต์ที่ combat ยังไม่รองรับ
4. เก็บเวลา kill/เดิน/ฟาร์ม/บอส แล้วปรับ EXP และเศรษฐกิจ ก่อน deploy ชุดรวม

การสร้างภาพใช้ GPT ตามค่าเริ่มต้นผู้ใช้: ภาพฐานและแอนิเมชันจากดีไซน์ของเกมเอง ดูในเกมก่อน เก็บ prompt, provider report และ source hashes ไม่ใช้ภาพ ชื่อเฉพาะ หรือสไปรต์จากเกมอ้างอิงเป็นต้นฉบับ

## Reference ที่ผู้ใช้ให้

- [PoE2DB — Unique item ภาษาไทย](https://poe2db.tw/th/Unique_item): ใช้อ้างอิงโครงสร้างรายการความสามารถประจำรุ่น ค่าที่สุ่มภายในช่วง และข้อแลกเปลี่ยน ไม่คัดลอกอุปกรณ์หรือเอฟเฟกต์ทั้งชิ้น
- [RateMyServer — Card database](https://ratemyserver.net/index.php?page=item_db&item_type=6): ใช้อ้างอิงความเป็นการ์ดเฉพาะมอน ตำแหน่งอุปกรณ์ และเอฟเฟกต์ที่มีเงื่อนไข รายการที่ลิงก์เป็น Pre-Renewal; ไม่ใช้ตัวเลขนั้นเป็นสูตรสมดุลของเกมเรา

สถานะของระบบทดลองระบุไว้ด้านบน ส่วนการจัดแมปและมอนครบชุดยังเป็นแผน ไม่มีการ deploy หรือเปลี่ยนข้อมูลผู้เล่นจริงในรอบนี้
