# แผนโลกและการผลิต Lv.1–100

22 ตุลาคม 2026 · แผนหลักและบันทึกชุดรวม Lv.1–100

## สถานะชุด Lv.100

เปิดพื้นที่ล่าครบ18ภูมิภาคถึงLv.100 เพิ่ม7โซนพร้อมมอน/การ์ด/วัสดุ52ชุดและUnique7ชิ้น เส้นEXP กฎส่วนต่างเลเวล migrationPostgreSQLจริง และเรดแยกตามปาร์ตี้อยู่ในชุดนี้ รายละเอียดผลตรวจและขอบเขตปัจจุบันอ่าน [ชุดโลก Lv.1–100](world-lv100-release.md) ข้อความและcheckpointด้านล่างเก็บประวัติการผลิตก่อนรอบนี้

## Checkpointก่อนหน้า — ปิดรอบ 22 ต.ค. 2026 เวลา 06:54 น.

ยังค้าง EXP/กฎส่วนต่างเลเวล การเก็บเวลาหลายอาชีพและเศรษฐกิจ ภารกิจปลดล็อก cap ตัวละคร 100 และ migration PostgreSQL ตลอดจนเรด/เนื้อหาที่เหลือ ตัวละครยัง cap99 แม้สุ่มออฟจะรองรับ item level100 แล้ว `output/world-current-checkpoint-20261022/status.json` เป็นรายการตรวจเทียบ plan กับข้อมูล runtime และหลักฐาน browser รายภูมิภาค

## ขอบเขตที่ยืนยัน

ผู้ใช้ขอวางแผนโลกถึง Lv.100 ก่อน แล้วจึงลงมือผลิตเป็นชุดเดียว หิมพานต์เป็นภูมิภาคแรกหลังชุดกรีก งานผลิตแบ่งเป็นชุดย่อยในเครื่องเพื่อวัดผลและแก้ปัญหาได้ แต่รวมตรวจและปล่อยพร้อมกันตามข้อตกลง ส่วนแผนด้านล่างเก็บขอบเขตที่วางไว้ก่อนผลิต ความคืบหน้าที่ทำและตรวจจริงอยู่ในสถานะล่าสุดและ checkpoint ท้ายเอกสาร

แหล่งข้อมูลกลาง: `maps/biome-plan.json` หน้าเปิดดูและเลือกภูมิภาค: http://localhost:5185/world-design.html

- ฐานเดิมก่อนเริ่มงาน: 7 ภูมิภาคในเกมถึง Lv.49
- แผนเพิ่ม 10 ภูมิภาคปกติ Lv.50–99 และ 1 ภูมิภาค Endgame Lv.100 รวม 11 ภูมิภาคใหม่
- ภูมิภาคปกติใหม่แต่ละแห่ง: มอนปกติ 5 ชนิด + Elite 2 ชนิด + บอส 1 ตัว รวมแห่งละ 8 ชนิด
- Lv.100: ผู้พิทักษ์ Elite 3 ตน + บอสเรด 1 ตัว
- รวมแบบเสนอมอนใหม่ **84 ชนิด / การ์ด 84 ใบ / วัตถุดิบเฉพาะ 84 ชนิด / Unique ประจำบอส 11 ชิ้น**
- ตัวเลขในเอฟเฟกต์เป็นค่าตั้งต้นเสนอเพื่อทดสอบ ไม่ใช่ผลสมดุลที่ตรวจแล้ว

## จุดที่ต้องเตรียมระบบก่อน

ตรวจโค้ดแล้วพบข้อจำกัดจริงที่ต้องแก้ก่อนทำเนื้อหาช่วงใหม่:

| จุดปัจจุบัน | งานที่ต้องทำ |
|---|---|
| `shared/data/stats.json` กำหนด maxLevel 99; `schema.ts` ใช้ literal 99 และ EXP array ยาว 99 | กำหนด EXP 99→100, ค่า terminal ของ Lv.100 และขยาย validation โดยรักษาค่า EXP เดิม |
| CharacterSchema และ MonsterSchema จำกัด 99 | ขยายถึง 100 รวม client/server profile และการโหลดข้อมูล |
| `server/sql/001_init.sql` มี CHECK level BETWEEN 1 AND 99 | เพิ่ม migration ใหม่แก้ constraint โดยเก็บตัวละคร/ไอเทมเดิมครบ ไม่แก้ migration เก่าที่ย้ายแล้ว |
| GM `/gm level` รับ 1–99; tests ปัจจุบันปฏิเสธ 100 | ปรับคำสั่ง สิทธิ์ ข้อความ และ regression test เมื่อเริ่มทำระบบ |
| `shared/src/item-rolls.ts` ItemRollSchema และ rollEquipment จำกัด itemLevel 10 | ออกแบบ version/tier สำหรับ 1–100, ช่วงออฟและ validation; ของเก่าไม่สุ่มซ้ำและไม่เสียค่าเดิม |
| สมดุลอุปกรณ์ระดับสูงกับ affix ใหม่ยังไม่ได้ตรวจรวม | ตรวจฐานอุปกรณ์ที่มีอยู่ก่อนเติมที่ขาด และทดสอบ damage/HP/economy ต่อ tier |
| เนื้อหาเรดต้องใช้ lifecycle แยกจาก field boss | ตรวจขนาดปาร์ตี้ แล้วพัฒนา party instance, checkpoint, wipe/reset, rejoin และสิทธิ์รางวัล |

Lv.100 ใช้ EXP แสดง MAX และไม่มีการเลเวลต่อ 101 ยังไม่ออกแบบ Paragon หรือเพิ่มแต้มไม่สิ้นสุด บอส Lv.100 ยากด้วยกลไกและค่าสถานะ ไม่ต้องเพิ่มเลเวลเหนือเพดานเพื่อทำให้ยาก

## ทางเลือกและการเดินทาง

- เมืองสี่ประตูยังเป็นฐานตลาด คลัง อาชีพและรวมปาร์ตี้ ภูมิภาคเริ่มต้นมีช่วงล่าใกล้เมืองก่อนลึกขึ้น
- ช่วง Lv.50–99 มีสองทางเลือกต่อช่วง 10 เลเวล เลือกจากของที่อยากล่าและสไตล์เล่นได้ ไม่บังคับเคลียร์ทั้งสองสาย
- เส้นทาง Lv.50/60 เป็นการสำรวจระยะไกลจากภูมิภาคเดิมตามแผน จึงต้องทำภารกิจเดินทาง/แคมป์ก่อนเปิด ไม่ได้เพิ่มประตูที่เดินเข้าจากเลเวลต่ำโดยไม่เห็นคำเตือน
- เส้นทางใหม่ Lv.70–99 เชื่อมข้ามสายได้ตามกราฟใน biome-plan.json เช่น หิมพานต์/ทะเลทราย → นครมังกร; โยไค/นครมังกร → หมู่เกาะ; ป่าสนธยา/หมู่เกาะ → บรรพกาล
- เข้ารอยต่อพิภพเมื่อ Lv.100 และผ่านภารกิจฝึกบทบาทกับบอสปลายทางสายใดสายหนึ่ง ไม่ต้องฟาร์มทุกตำนาน
- แผนที่แต่ละภูมิภาคมีจุดเข้าปลอดภัย ค่ายพัก 3 จุด ทางวนสั้นสำหรับ solo ทางแยกล่า Elite และลานบอสอ่านวงเตือนได้
- แผนที่ใหม่ปกติตั้งต้นประมาณ 160×128 ถึง 192×160 เมตร ขนาดจริงปรับตามมุมกล้องและเส้นทางหลังทดสอบเดิน
- ประชากรตั้งต้นต่อภูมิภาคปกติ: มอนปกติชนิดละ 8 ตัว = 40; Elite ชนิดละ 3 = 6; บอส 1 รวมประมาณ 47 ตัว ปรับหลังวัดเวลาเดิน การแย่งมอนและโหลด server
- ตำนานเป็นแกนของรูปร่าง/บรรยากาศ แต่ภาพและเครื่องแต่งกายออกแบบใหม่เป็นต้นฉบับของเกม

## ส่วนต่างเลเวลและความเร็วเติบโต — ค่าตั้งต้นเสนอ

ให้ Δ = เลเวลมอน − เลเวลผู้เล่น แสดงระดับอันตรายก่อนเข้าโซน แนะนำล่าภายใน ±5 โดยไม่มี hard lock ของการเดินทาง

| Δ | EXP เสนอ | เหตุผล |
|---|---:|---|
| −2 ถึง +3 | 100% | ช่วงล่าปกติและเปรียบเทียบสอง biome ใน tier เดียวกัน |
| −3 ถึง −5 | 70% | ยังช่วยเพื่อนและเก็บของได้ |
| −6 ถึง −9 | 30% | ลดการฟาร์ม EXP ในพื้นที่อ่อนกว่าเกินไป |
| ≤ −10 | 10% | กลับไปล่าการ์ดได้ แต่ไม่ใช่ทางเก็บเวลาหลัก |
| +4 ถึง +5 | 105% | รางวัลเพิ่มเล็กน้อยเพื่อความท้าทาย ไม่กระโดดหลาย tier |
| ≥ +6 | 25% และจำกัดฐาน EXP เทียบมอนผู้เล่น +5 | ลดการพาเลเวลต่ำล่าบอสข้ามช่วง |

ตารางนี้เป็นแผน ไม่ได้เปลี่ยน EXP ในเกมปัจจุบัน สิทธิ์ปาร์ตี้ต้องนับการมีส่วนร่วมจากโจมตี ฮีล และป้องกัน ไม่ใช้ดาเมจอย่างเดียว ไม่ลดโอกาสการ์ด/Unique เพราะผู้เล่นเลเวลสูงโดยอัตโนมัติ เพื่อให้กลับมาหาของบิลด์เก่าได้

เป้าหมายทดสอบ: มอนปกติเลเวลใกล้กันใช้เวลา 8–12 วินาที, Elite 30–60 วินาทีสำหรับบิลด์เหมาะสม, field boss กลุ่ม 3–6 นาที และเรด Lv.100 ราว 8–12 นาที ต้องวัดกับหลายอาชีพและหลายระดับอุปกรณ์ก่อนล็อกตัวเลข ไม่ปรับ HP อย่างเดียวจนกลายเป็นถุงเลือด

## กติกาอุปกรณ์ การ์ด Unique และดรอป

- ของสุ่มออฟ 8 ตระกูลเดิมใช้ตาราง 11 tier ข้างต้น โดยตรวจฐานอุปกรณ์ที่มีอยู่ก่อนเพิ่มรายการใหม่ Magic สูงสุด 1 Prefix + 1 Suffix; Rare สูงสุด 3+3; ห้าม affix family ซ้ำในชิ้นเดียว
- Flat stats โตตาม tier; ค่าร้อยละมีเพดานต่อหมวด ไม่คูณตามเลเวลตรง ๆ จนโตเกินควบคุม Affix ranges และ item level ตรวจฝั่ง server
- ค่าสุ่มเกิดเมื่อดรอปและติดชิ้นเดิมผ่านหยิบ คลัง แลก สวม/ถอด; migration ของเวอร์ชันใหม่ต้องอ่านของเดิมได้
- การ์ดแต่ละชนิดมี id ช่องและเอฟเฟกต์ของตัวเองในแผน การ์ดระดับต้นยังมีหน้าที่ได้ด้วยเงื่อนไข ไม่บังคับให้เลเวลสูงแรงกว่าเสมอ ต้องทดสอบผลรวมหลายช่อง
- Unique มีบรรทัดความสามารถประจำชิ้นและช่วงค่าสุ่มของตน มีข้อแลกเปลี่ยน; ไม่ใช้ตารางสุ่ม Prefix/Suffix ของ Rare และไม่ใส่การ์ดตามข้อตกลงชุดแรก
- ค่าดรอปเริ่มต้นเสนอ: การ์ดปกติ 0.1%, Elite 0.2%, Boss 0.5%; วัตถุดิบ 65% / 85% / 100%; อุปกรณ์สุ่มออฟ 3.5% / 6% / 30%; Unique ใหม่จากบอสเจ้าของ 3% ต่อ clear ก่อนตัวคูณเดิม
- อัตราข้างต้นยังไม่แก้ของชุด Lv.1–49 ที่เล่นอยู่ และต้องทดสอบเวลาหาของจริงก่อนใช้ทั้งโลก
- Material แต่ละชนิดใช้สูตรคราฟต์/ซ่อม/ปรับอุปกรณ์ใน tier ของตน ค่าขายเพิ่มเป็นขั้นอย่างมีเพดาน ไม่ใช้มอนขั้นสูงเป็นเครื่องพิมพ์ทอง ต้องทำบัญชี gold เข้า/ออกจาก potion, repair, forge และการขายของ
- Proc ทุกชนิดมีขอบเขต/คูลดาวน์; DOT, reflect และสิ่งเรียกไม่เรียก proc ต่อโซ่; บอสควบคุมยากใช้ผลลดรูป ไม่โดน stun lock ถาวร
- ผู้ช่วยและร่างลวงไม่มี EXP/ทอง/ดรอป; server ตัดสินสิทธิ์ loot และทำ transaction เพียงครั้งเดียว

## Endgame Lv.100

เรดเป็นแผนระบบใหม่: โถงเตรียมตัว → ผู้พิทักษ์สามหลัก → checkpoint → อสูรแกนโลก เป้าหมายกลุ่มเริ่มต้น 4–6 คน แต่ต้องตรวจข้อจำกัดระบบปาร์ตี้ก่อนล็อกจำนวน ไม่พึ่งอาชีพใดอาชีพหนึ่งเพื่อข้ามกลไกที่ไม่มีทางเลือก

ภารกิจผู้พิทักษ์ฝึกการช่วยเพื่อน รับท่า/ตัดจังหวะ และปิดจุดพร้อมกัน เมื่อบอสเรดเปลี่ยนช่วง สนามเปิดช่องปลอดภัยที่อ่านได้เสมอ ตรวจว่าแบบลดเอฟเฟกต์ยังเห็นวงเตือน ผู้เล่นที่ตายกลับ checkpoint แล้วเข้าต่อได้ตามสถานะ encounter; wipe/reset/rejoin ต้องไม่ให้รางวัลซ้ำ

เมื่อถึง cap ผู้เล่นไล่การ์ด Unique วัตถุดิบคราฟต์ และบิลด์ทางเลือก ไม่เพิ่มเพดานเลเวลหรือระบบแต้มไม่สิ้นสุดในชุดนี้ ยังไม่วาง PvP season, auction หรือระบบขายของเงินจริงเป็นเงื่อนไขของแผน

## ลำดับผลิตเพื่อรวมปล่อยครั้งเดียว

1. **รองรับ Lv.100 และยืนยันข้อมูลเดิม** — ขยายเพดานตัวละคร/มอนและตาราง EXP 99→100; migration CHECK ฐานข้อมูลและ round-trip save/load; ขยายสุ่มออฟที่ปัจจุบันจำกัด item level 10 ไปเป็น tier 1–100 พร้อม version/validation และรักษาของเก่า; ทดสอบเก็บเวลผ่าน 98→99→100 และแสดง MAX; ตรวจข้อจำกัดปาร์ตี้และสร้าง party instance / checkpoint สำหรับเรด Lv.100; ยืนยัน rules ส่วนต่างเลเวลและสิทธิ์ดรอปฝั่ง server ก่อนปรับเศรษฐกิจ

2. **หิมพานต์ก่อน แล้วอียิปต์** — Tiled + collision + minimap + เส้นทางเดินทาง; ภาพ/แอนิเมชันมอนและไอคอนพร้อม provenance; AI วงเตือน ดรอป การ์ด Unique และ playtest

3. **นอร์สและโยไค** — ดินแดน Lv.60–69 และชุดอุปกรณ์ T7; ทดสอบสายตั้งรับและหลบเคลื่อนที่เทียบกัน

4. **นครมังกรและภูเขาไฟ** — ดินแดน Lv.70–79 และชุดอุปกรณ์ T8; ทดสอบสลับธาตุและดาเมจต่อเนื่อง ไม่ให้ proc ต่อโซ่

5. **ป่าสนธยาและหมู่เกาะ** — ดินแดน Lv.80–89 และชุดอุปกรณ์ T9; ทดสอบวงพื้นที่ ภาพลวง และเส้นทางน้ำ

6. **ทะเลดาวและบรรพกาล** — ดินแดน Lv.90–99 และชุดอุปกรณ์ T10; ทดสอบสถานะผสม ค่าสะสม และโหลด combat

7. **รอยต่อพิภพ Lv.100** — โถงเตรียมตัว checkpoint ผู้พิทักษ์และเรด; สิทธิ์รางวัลปาร์ตี้และ idempotent pickup หลังบอสตาย; ทดสอบ wipe กลับเข้า instance และรีเซ็ตโดยไม่เพิ่มรางวัลซ้ำ

8. **รวมตรวจและปล่อยครั้งเดียว** — ตรวจใบอนุญาต/ที่มาภาพและ QA ทุกมอนทุกท่า; balance แผนที่ การ์ด Unique และเศรษฐกิจรวม; ทดสอบ migration กับ PostgreSQL + tests + build + browser playtest; รวมชุด release แล้ว deploy ตามการอนุมัติที่มีในขณะนั้น

## งานภาพและการตรวจรับ

- ใช้ Sprite-Gen/GPT ตามค่าที่ผู้ใช้เลือก: ภาพฐาน → มุมหน้า/หลัง → idle/move/attack/hit/death → สกัดและตรวจ → ดูในเกมก่อน
- แต่ละชนิดมี 4 pose ต่อท่าต่อมุมเป็นฐานเริ่มต้น แล้ว mirror เป็น 4 ทิศ บอสหรือร่างยาวต้องตรวจว่าจำเป็นต้องวาดเพิ่มแทน mirror หรือเพิ่มเฟรม
- แบบเสนอ 84 ชนิดเท่ากับ 420 motion atlas และ 3,360 pose ต้นฉบับก่อน mirror หากใช้ฐาน 5 ท่า × 2 มุม × 4 pose ตัวเลขนี้เป็นขอบเขตงาน ไม่ใช่ไฟล์ที่สร้างแล้ว
- Body plan ต้องตรงสัตว์จริงในแบบ: จำนวนขา ปีก หาง งวง/คอ และของที่ถือ ห้ามใช้ recolor เพื่อแทนชนิดใหม่ที่มีพฤติกรรมต่างกัน
- เก็บ prompts, provider receipts, ต้นฉบับ, QA และ checksum ไม่ใช้ภาพจากเกมอื่นและไม่เลียนแบบชุดตัวละครแฟรนไชส์
- โหลดภาพเฉพาะภูมิภาคที่เข้า วัด compressed transfer, decoded texture memory และ FPS ต่อแมป เป้าหมายเริ่มต้นประมาณไม่เกิน 12 MB สำหรับแพ็กมอนต่อภูมิภาค ต้องวัดจริงจากไฟล์ก่อนรับเข้า
- ทดสอบเส้นทางจาก entry ไปทุก camp/habitat/boss/gate และกลับเมือง ใช้ Tiled/collision ร่วมกันทั้ง server, client และ minimap
- ตรวจทุกมุม ทุกท่า ทุกเฟรม ความชัดที่ขนาดเกม ขอบคลิก อาการทะลุฉาก และวงเตือนที่ตรงเวลาทำดาเมจ
- ตรวจสุ่มของ/การ์ด/Unique ตรงตัว, ตาย/เกิดใหม่, รางวัลสิ่งเรียก, save/load/rejoin และปาร์ตี้หลายบทบาท
- ก่อนรวม release: migration PostgreSQL จริง, automated tests/build, browser playtest, balance หลายอาชีพ และยืนยัน provenance ครบ จึงรวม deploy ตามข้อตกลงขณะปล่อย
