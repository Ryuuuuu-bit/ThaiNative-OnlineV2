# Item artwork, batch one

191 live inventory / trade / bestiary icon overrides: 56 rolled equipment bases (seven families × eight slots), 13 Uniques, 11 starter materials and 111 monster cards. Item IDs, affixes, effects, requirements and drop rates are unchanged.

New equipment and treasures were generated from the retained text prompts through Sprite-Gen's GPT (`codex`) provider. Five native-alpha sheets contain 16 original objects each. No external game artwork or artist references were provided. The project approved the initial visual target by inspecting sheet 1 and its normalized icon on a dark inventory background before completing the set. Generation receipts preserve the provider, prompt and empty reference arrays; this records provenance, not a legal clearance opinion.

All 111 cards deterministically reuse the project's existing approved creature bases and newly authored vector borders. Boss cards have gold borders/crowns; the upper corner gem follows the monster's actual element. The card filename follows the template ID, including the two legacy cards whose data still shares `card_crag_titan` as an icon alias. One missing retained base, `clay_puff`, was restored from the original output only after matching its recorded SHA-256.

Static objects were extracted with the canonical Sprite-Gen `slice-sheet` command, 4×4 grid, native alpha, alpha floor 64, 192×192 canvas, baseline 178, target height 164 and contain fit. Every cell reports zero clipped pixels. The packer applies a uniform eight-pixel canvas inset to protect wide silhouettes in inventory slots. Shipping source sheets, prompts, receipts, slicing reports and normalized cuts are retained here. `public/assets/item-art-v2/manifest.json` records each shipping file and its source hash.

Rebuild cards and publish already approved cuts using the Sprite-Gen virtual environment's Python (Pillow is already available):

```
python meadow-3d/tools/build-card-art-v2.py
python meadow-3d/tools/pack-item-art-v2.py
```

The runtime registry is generated by the second command. It overrides only this batch, preserving existing atlas fallbacks. The review page `/loot-art-review.html` uses the same `itemIconCell` resolver as inventory, trade and monster drops, with native 32/48/96px views. The isolated local demo runs on port 5201; no deployment is part of this artwork batch.

Other materials, potions, scrolls and legacy shop equipment remain in their existing art sets; they are candidates for subsequent batches. Card illustrations follow the current creature art, including older monsters that still share a visual base.
