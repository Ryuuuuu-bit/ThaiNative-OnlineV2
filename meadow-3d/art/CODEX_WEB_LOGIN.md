# Codex task: web portal + account login for The Beginning Online (meadow-3d)

Read first: `meadow-3d/README.md`, `meadow-3d/index.html`, `meadow-3d/character.html`, `meadow-3d/src/main.ts`, `meadow-3d/src/sim.ts`, `meadow-3d/src/style.css`, `meadow-3d/vite.config.ts`, root `package.json`, `serve.mjs`, `railway.json`, `server/package.json` (the `server/` folder is an empty Colyseus skeleton with no `src/`; you will replace it).

Goal: turn the single-page demo into a small web game with accounts. Players land on a painted portal page, play instantly as a guest, optionally link Google later, pick/create a character, and their progress is saved on the server. Everything (static site + REST API) runs as ONE Node process on Railway. Keep the gameplay, art and HUD exactly as they are; this task is the web shell and the account layer around them.

## 2. Server (`server/`, TypeScript, Node 22, no framework beyond Express 5)

Replace the skeleton: `server/src/index.ts` (boot), `app.ts` (Express app factory for tests), `routes/auth.ts`, `routes/characters.ts`, `store/{types,memory,postgres}.ts`, `session.ts`, `google.ts`, `static.ts`, `sql/001_init.sql`. Keep `server/package.json` minimal: `express`, `pg`, `google-auth-library`, `cookie`, dev: `tsx`, `typescript`, `@types/*`. Remove the Colyseus/drizzle/redis deps and `ecosystem.config.cjs`. Scripts: `dev` (tsx watch, PORT 8787, memory store unless `DATABASE_URL`), `build` (tsc → `build/`), `test` (`node --test build/**/*.test.js` after build, or `tsx --test`).

- **Store interface** (`store/types.ts`): accounts `{id, kind:'guest'|'google', googleSub?, displayName, createdAt, lastLoginAt}`, sessions `{id, accountId, tokenHash, expiresAt, createdAt, userAgent}`, characters `{id, accountId, name, nameKey (lowercased, unique), level, xp, gold, kills, potions, posX?, posZ?, createdAt, lastPlayedAt, deletedAt?}`. `MemoryStore` for dev/tests; `PostgresStore` using `pg` Pool, running `sql/001_init.sql` on boot (`CREATE TABLE IF NOT EXISTS`, tables prefixed `tn2_` so old tables in the same UAT database are untouched). Choose the store from `DATABASE_URL`.
- **Sessions**: opaque 32-byte random token in an `httpOnly; SameSite=Lax; Secure (when `NODE_ENV=production` or `X-Forwarded-Proto=https`); Path=/; Max-Age 30 d` cookie `tn_session`; store only the SHA-256 hash. `app.set('trust proxy', 1)` for Railway. Guest accounts additionally get a `guestKey` (random, returned once and kept by the client in `localStorage`) so a guest who lost the cookie can call `POST /api/guest/resume {guestKey}` to get a new session — otherwise guests would lose everything on a cleared cookie.
- **Routes** (JSON, errors `{error:{code,message}}`, Thai messages):
  - `GET /api/config` → `{googleClientId|null, build}`.
  - `POST /api/guest` → create guest account + session; `{account, guestKey}`.
  - `POST /api/guest/resume {guestKey}`.
  - `POST /api/google {credential}` → verify the ID token with `google-auth-library` against `GOOGLE_CLIENT_ID`; if the current session is a guest account, *link* it (set kind google + googleSub, keep characters); else find-or-create the google account; new session. Reject if the sub is already bound to another account (409, Thai message).
  - `GET /api/me` → `{account, selectedCharacterId}` or 401.
  - `POST /api/logout`.
  - `GET /api/characters`, `POST /api/characters {name}` (slot and name rules, 409 on duplicate), `DELETE /api/characters/:id` (soft delete), `POST /api/characters/:id/select`, `GET /api/characters/:id` (full progress), `POST /api/characters/:id/progress {level,xp,gold,kills,potions,posX,posZ}` — server clamps: level 1–99, non-negative ints, level/xp/gold may only move within sane bounds per save (e.g. level ≤ previous+3, gold ≤ previous+5000) to stop trivial tampering; accept `text/plain` bodies too because `sendBeacon` sends them.
  - `GET /healthz` → `ok`.
- Rate limit `POST /api/guest` and `/api/google` per IP (in-memory, 20/min). Body limit 16 kB. Basic `X-Content-Type-Options`, `Referrer-Policy`, and a CSP that allows `accounts.google.com` + Google Fonts.
- **Static**: serve `meadow-3d/dist` (env `STATIC_DIR`), immutable cache for hashed `/assets/*`, `no-cache` for HTML, unknown non-API routes → `index.html`. This replaces `serve.mjs` (delete it).
- **Root scripts**: `build:server` (`npm --prefix server ci && npm --prefix server run build`), `build:web` (= current `build:meadow` with `VITE_BUILD_ID` from `RAILWAY_GIT_COMMIT_SHA` short or date), `build` = both, `start` = `node server/build/index.js`, `test:server`, `test` = meadow + server. Update `railway.json`: `buildCommand: npm run build`, `startCommand: npm start`, keep the healthcheck.
- Env: `PORT`, `DATABASE_URL`, `GOOGLE_CLIENT_ID` (optional), `SESSION_SECRET` (optional pepper mixed into the token hash), `STATIC_DIR`. Document in `server/README.md`.
